# Pilot readiness

Implemented: generic profiles/evidence, job/company notes, stages and history, session-derived ownership, per-account duplicate detection, versioned PDFs, protected downloads, backup export, bounded storage, fictional demo, preparation prompt handoff, CI and repository boundary tests.

Before accounts open: create GitHub repo; grant Vercel team write access; link project; connect a free Postgres database; set environment keys; run migrations; verify actual signup/signin/signout, sessions, two-account isolation, PDF uploads/downloads and backup; configure recovery/email verification before broad signup.

After a small pilot: measure costs and usage, gather real failure cases, add scoped assistant access, add deletion/retention controls before a wider launch, assess object storage, review accessibility/abuse controls and test backup recovery.

The original personal dashboard and schedule are not migrated until authenticated replacement access is verified.
